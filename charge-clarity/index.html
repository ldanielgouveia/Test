How to download your activity from Chase
  1. Sign in at chase.com on a computer. The mobile app can't export files.
  2. Open an account (checking or a credit card) and select the download icon above the transaction list.
  3. Choose Spreadsheet (Excel, CSV), pick a date range (a year or more gives the best recurring-charge detection), and download.
  4. Repeat for each Chase account, then select Import Chase CSV here, or drop the files onto this page. You can import several at once.

Files are read in this browser only and kept on this device so they're here next time. Nothing is uploaded. Re-importing overlapping date ranges is safe; duplicates are skipped.
